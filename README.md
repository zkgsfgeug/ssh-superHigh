# English Documentation

## What is Arvin Shadow SSH?

Arvin Shadow SSH is a powerful tool that transforms regular SSH connections into **ultra-fast tunnels** using UDP acceleration, BBR congestion control, and kernel optimizations. It provides **5-10x faster speeds** compared to standard SSH.

## Features

| Feature | Description |
|---------|-------------|
| ⚡ **Ultra Speed** | 5-10x faster than regular SSH |
| 🔄 **Auto Booster** | UDPspeeder + UDP2RAW built-in |
| 🛡️ **Anti-Filter** | Bypass firewall restrictions |
| 📊 **Traffic Limit** | Per-user bandwidth control |
| ⏰ **Expiry Date** | Automatic account expiration |
| 🎛️ **Easy Panel** | Simple CLI management |
| 🔗 **Dual Config** | Regular + Shadow outputs |

## Requirements

- Linux Server (Ubuntu 20.04+, Debian 11+)
- Root access
- OpenSSL
